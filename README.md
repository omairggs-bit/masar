# Masar | مسار

منصة **وساطة شحن** تجمع أفضل أسعار الشحن المحلي والدولي من كبرى الشركات في مكان واحد، بما فيها الشحن إلى السودان عبر تاركو.

A shipping brokerage platform that compares local and international rates from carriers like DHL, FedEx, Aramex and Tarco in one place.

## المزايا | Features

- **حاسبة أسعار** تقارن بين شركات الشحن بسعر شفاف من أول ريال
- **تتبّع الشحنات** من الطلب إلى الوجهة
- رحلة واضحة للتاجر في 5 خطوات
- **ثلاث لغات:** العربية، الإنجليزية، الأردو
- محرك الحساب والتتبّع مكتوب بـ **Rust وC++ ومحوّل إلى WebAssembly**، وتشرحه صفحة `technology.html`
